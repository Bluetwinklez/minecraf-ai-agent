# minecraf-ai-agent

AI agent workspace for Minecraft mod development.

## Skills (`.claude/skills/`)
| Skill | Purpose |
|---|---|
| `mc-mod-setup` | Project setup, loader/version choice (Fabric, NeoForge, Forge) |
| `mc-mod-content` | Items, blocks, entities, recipes, datagen |
| `mc-mod-mixins` | Mixins, events, access wideners |
| `mc-mod-build-test` | Build, run, crash triage |
