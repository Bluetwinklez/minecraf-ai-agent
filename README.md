# minecraf-ai-agent

AI agent workspace for Minecraft mod development, focused on NPC mods.

## Skills (`.claude/skills/`)
| Skill | Purpose |
|---|---|
| `mc-mod-setup` | Project setup, loader/version choice (Fabric, NeoForge, Forge) |
| `mc-mod-content` | Items, blocks, entities, recipes, datagen |
| `mc-mod-mixins` | Mixins, events, access wideners |
| `mc-mod-build-test` | Build, run, crash triage |
| `mc-npc-entity` | NPC entity, attributes, renderer, spawning, saved data |
| `mc-npc-ai` | Goals, Brain, pathfinding, routines |
| `mc-npc-interaction` | Dialogue GUI, trading, quests, packets |
| `mc-npc-llm` | LLM (Claude API) driven NPC dialogue and actions |
| `caveman-mode` | Terse reply style, keeps code/game ids verbatim |
| `adhd-mode` | Focused, step-by-step replies with clear next action |
